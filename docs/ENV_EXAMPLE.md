# Exemplo de variáveis de ambiente (Supabase)

Copie o bloco abaixo para um arquivo `.env.local` na raiz do projeto. **Não commitar `.env.local`.**

```env
# Supabase (exemplo — substituir pelos valores do seu projeto)
NEXT_PUBLIC_SUPABASE_URL=https://seu-projeto.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sua-anon-key
```

Obtenha a URL e a anon key no painel do Supabase: Project Settings → API.
